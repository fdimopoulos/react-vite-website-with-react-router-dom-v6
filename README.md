# Run the Application

1. Clone the repository.
2. Install the dependencies:
   npm install
3. Start the development server:
   npm run dev

# Packages Used

1. react-router-dom v6 - (Client-side routing.)
2. react-icons - (A collection of popular icon libraries for React.)
3. Swiper.js - (A touch-enabled slider used for the testimonials section.)
4. Formik - (A library for building and managing forms in React.)
5. Yup - (A JavaScript schema validation library used for form validation.)
6. Framer Motion - (A production-ready animation library for React.)
